如何匯出 GPX / KML 軌跡檔？

手機紀錄建議流程

  1. 先使用手機運動、健行或自行車紀錄 App 開始記錄路線。
  2. 完成旅程後停止紀錄，進入該筆活動紀錄。
  3. 找到「分享 / 匯出 / Export」功能。
  4. 選擇 GPX 或 KML 格式，儲存到手機檔案、雲端硬碟或傳到電腦。
  5. 回到本頁，先選擇交通方式，再上傳 GPX / KML 檔案。

Google 地圖 / 我的地圖

可在「Google 我的地圖」建立或整理路線，透過圖層選單匯出 KML/KMZ。若取得 KMZ，需先解壓縮或轉成 KML 後再上傳。

健行 / 運動 App

常見軌跡紀錄工具通常可於活動詳情中找到「匯出 GPX」。若只有分享連結，請確認是否能下載原始 GPX 檔。

GPS 裝置

Garmin、手持 GPS 或碼錶可透過官方軟體或 USB 匯出 GPX，建議保留時間戳記以利選擇起訖節點。

上傳前檢查

請避免上傳包含私人住家、公司精確位置的完整軌跡；可先裁切成活動區段，再匯入本系統。

小提醒

本系統需要軌跡檔內含時間節點，才能判斷「哪一段時間」的移動軌跡可用於登錄。GPX 通常較容易保留時間戳記；KML 若只有路線座標而沒有時間，只能做距離參考，不能登錄減碳。
